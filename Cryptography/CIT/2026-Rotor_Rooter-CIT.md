Model - Enigma M3

Reflector - UKW B

Rotors - I, II, III

Positions - A,A,A

Ring - A,A,A

Plugboard - empty

Output:-

```
wecan onlys eeash ortdn htanc eahea dbutw ecans eeple igyth ereth atnee dstob edone
```

This reads as:-

```
we can only see a short distance ahead but we can see plenty there that needs to be done
```
