# Providence Accounting — Writeup

## Challenge

**Category:** Reverse / Excel / Math  
**Challenge:** Providence accounting  
**Flag:** `alfa{here_is_your_snack}`

The challenge provided a published Google Sheets page that looked like a provisioning terminal. The visible sheet contained eight input boxes and a large green/black output panel. Initially, the terminal displayed:

```text
ДОСТУП ЗАПРЕЩЕН
```

which means:

```text
ACCESS DENIED
```

The goal was to find the correct input that changes the terminal state and reveals the flag.

---

## Step 1 — Download the spreadsheet

The sheet was opened in `htmlview`, so the normal Google Sheets **File** menu was not visible. Instead, I downloaded the file directly by changing the URL to an XLSX export endpoint:

```bash
wget -O providence.xlsx "https://docs.google.com/spreadsheets/d/1LDAeCB7-vl7IhpZFvCsZCB1Sdn59m5wsccmAsTOftcA/export?format=xlsx"
```

Then I extracted it like a ZIP archive:

```bash
mkdir -p xlsx
unzip -o providence.xlsx -d xlsx
```

---

## Step 2 — Dump formulas from the workbook

Since `.xlsx` files contain spreadsheet formulas, I used `openpyxl` to inspect the workbook:

```python
from openpyxl import load_workbook

wb = load_workbook("providence.xlsx", data_only=False)

for ws in wb.worksheets:
    print("SHEET", ws.title, "state=", ws.sheet_state)
    for row in ws.iter_rows():
        for c in row:
            if isinstance(c.value, str) and c.value.startswith("="):
                print(ws.title, c.coordinate, c.value)
```

This revealed multiple hidden sheets:

```text
SHEET Panel state= visible
SHEET s1 state= hidden
SHEET s2 state= hidden
SHEET s3 state= hidden
```

The main success condition was in `Panel!B11`:

```excel
=IF(
  AND(
    COUNTIF('s1'!$B$4:$I$4,1)=8,
    COUNTIF('s1'!$J$14:$Q$14,1)=8
  ),
  "ДОСТУП РАЗРЕШЕН",
  "ДОСТУП ЗАПРЕЩЕН"
)
```

So the sheet grants access only when:

```text
s1!B4:I4   are all 1
s1!J14:Q14 are all 1
```

The hidden sheet `s1` referenced eight cells from the visible `Panel` sheet:

```text
s1!B2 = Panel!Z6
```

These corresponded to the eight blue input boxes shown at the top of the panel.

## Step 4 — Dump hidden sheet values

Next, I dumped the values from hidden sheet `s1`:

```python
from openpyxl import load_workbook

wb = load_workbook("providence.xlsx", data_only=True)
ws = wb["s1"]

def row_values(r, c1, c2):
    return [ws.cell(r, c).value for c in range(c1, c2 + 1)]

print("[target A18:H18]")
print(row_values(18, 1, 8))

print("\n[char lookup A23:I48]")
for r in range(23, 49):
    print(r, row_values(r, 1, 9))

print("\n[constants/matrices rows 30:42, E:BF]")
for r in range(30, 43):
    print(r, row_values(r, 5, 58))
```

The target vector was:

```text
[92, 97, 27, 240, 199, 80, 217, 23]
```

The lookup table showed that valid input characters were lowercase letters `a-z`, mapped to their ASCII values:

```text
a -> 97
b -> 98
c -> 99
...
z -> 122
```

The formulas in `s1` used modular arithmetic over `251`, `SUMPRODUCT`, and matrix-like constants. Solving these equations produced the 8-byte input:

```text
x l m a t r i x
```

So the access code was:

```text
xlmatrix
```

## Step 5 — Fill the code into the spreadsheet

The eight blue boxes corresponded to:

```text
Z6, AD6, AH6, AL6, AP6, AT6, AX6, BB6
```

I wrote the code into those cells:

```python
from openpyxl import load_workbook

wb = load_workbook("providence.xlsx")
ws = wb["Panel"]

cells = ["Z6", "AD6", "AH6", "AL6", "AP6", "AT6", "AX6", "BB6"]
code = "xlmatrix"

for cell, ch in zip(cells, code):
    ws[cell] = ch

wb.save("solved.xlsx")
print("saved solved.xlsx with code:", code)
```

After opening the file and recalculating, the banner changed to:

```text
ДОСТУП РАЗРЕШЕН
```

which means:

```text
ACCESS GRANTED
```

## Step 6 — Understand the visual output

At first, the green/black grid still looked unreadable. Dumping the visible grid values gave only `1`s, because the visual grid was not the real source of the flag.

Inspecting the XML formulas showed that each cell in the visible grid `B14:CD39` was calculated from hidden sheet `s3`:

```excel
=BITAND(
  BITRSHIFT(
    INDEX('s3'!$P$2:$Y$27, ROW()-13, QUOTIENT(COLUMN()-2,8)+1),
    7-MOD(COLUMN()-2,8)
  ),
  1
)
```

So the panel was rendering bits from:

```text
s3!P2:Y27
```

Then `s3!P2:Y27` was generated by XORing bytes from `s3!D2:M27` with a keystream derived from the input:

```excel
=BITXOR(
  INDEX($D$2:$M$27, ROW()-1, COLUMN()-15),
  INDEX($B$2:$B$261, (ROW()-2)*10+COLUMN()-15)
)
```

LibreOffice produced `#NAME?` for some Excel bit functions, so I reimplemented the byte generation in Python instead.

---

## Step 7 — Recreate the hidden image in Python

The access code was packed into four 16-bit words, then used to generate a byte stream. This stream was XORed with the encrypted bytes from `s3!D2:M27`.

```python
from openpyxl import load_workbook
from PIL import Image

MASK = 65536

def mod(x, m=MASK):
    return x % m

def bitxor(a, b):
    return int(a) ^ int(b)

code = "xlmatrix"
ch = [ord(c) for c in code]

B4 = ch[0] + 256 * ch[1]
C4 = ch[2] + 256 * ch[3]
D4 = ch[4] + 256 * ch[5]
E4 = ch[6] + 256 * ch[7]

stream = []
prevB, prevC, prevD, prevE = B4, C4, D4, E4

for a in range(65):
    F = mod(
        bitxor(prevB << 5, prevC >> 3)
        + bitxor(prevD, prevE << 1)
        + 25713
        + a * 911
    )

    G = mod(
        bitxor(prevC << 4, prevD >> 2)
        + bitxor(prevE, prevB << 2)
        + 12345
        + a * 1499
    )

    B = mod(bitxor(prevC, F))
    C = mod(bitxor(prevD, G))
    D = mod(bitxor(prevE, mod(B + 54321 + a * 577)))
    E = mod(bitxor(prevB, mod(C + 22222 + a * 313)))

    stream += [
        B & 0xff,
        (C >> 8) & 0xff,
        D & 0xff,
        (E >> 8) & 0xff,
    ]

    prevB, prevC, prevD, prevE = B, C, D, E

wb = load_workbook("solved.xlsx", data_only=False)
ws = wb["s3"]

cipher = []
for r in range(2, 28):
    for c in range(4, 14):
        cipher.append(int(ws.cell(r, c).value) & 0xff)

plain = [a ^ b for a, b in zip(cipher, stream)]

scale = 12
img = Image.new("RGB", (80 * scale, 26 * scale), "white")
pix = img.load()

for y in range(26):
    for byte_i in range(10):
        b = plain[y * 10 + byte_i]
        for bit in range(8):
            bitval = (b >> (7 - bit)) & 1
            color = (0, 0, 0) if bitval else (255, 255, 255)
            x = byte_i * 8 + bit
            for yy in range(y * scale, (y + 1) * scale):
                for xx in range(x * scale, (x + 1) * scale):
                    pix[xx, yy] = color

img.save("real_grid.png")
```

Opening `real_grid.png` revealed the flag text.
